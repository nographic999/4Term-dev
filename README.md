# 4Term

**4Term** is an advanced serial port terminal designed for monitoring and logging RS232 communication.  
It's especially useful for capturing, analyzing, and debugging data from serial devices in real-time.

![4Term icon](./assets/icon.png)

---

## Features

- **Macros:** 256 macros on 16 buttons, in 2 groups of 8 pages, with tooltips, keyboard shortcuts (Ctrl+1..8, Ctrl+Shift+1..8) and marks for scripts, risky commands and repeats.
- **Macro buffer (F9):** edit all 16 macros of a page at once over the output, while data keeps arriving.
- **Repeats:** give a macro a repeat interval and click its button to start or stop it; Ctrl+Shift+R stops all.
- **Highlights (F7):** up to 64 rules that color whole lines or just the matching text.
- **Timestamps** on output lines, **logging to a file**, **find** in the output (Ctrl+F) and a **hex view** (Ctrl+Shift+H).
- **Scripts** (`>load file.txt`), DTR/RTS control, auto-connect and local echo.

## Requirements

- Windows with .NET Framework 4.8.1
- Settings are stored in `config.xml` next to the program.
